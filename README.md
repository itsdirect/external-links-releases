# External Links for Guild Wars 2

An addon that lets external links perform actions in Guild Wars 2. Only chat links are currently supported.

Supported addon loaders:

- GW2Load

All addon loaders are enabled by default.

## Installation

Download the [latest relase](https://github.com/itsdirect/external-links-releases/releases/latest) and copy it to your addon folder (`<gw2 install dir>/addons/external_links/external_links.dll`).
The `gw2://` handler will be registered the first time the addon is loaded.

## Userscripts

Check out [userscripts](./userscripts) that can be installed using e.g. Tampermonkey.
